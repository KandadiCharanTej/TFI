# DECISIONS.md

One-line record of architecture, design, and engineering choices made during development.

- **2026-11-13 (Phase 0)**: Self-hosted all 5 font families (`Anton`, `Permanent Marker`, `Plus Jakarta Sans`, `Space Mono`, `Noto Sans Telugu` subset to Telugu + Latin) directly in `apps/web/public/fonts/*.woff2` extracted from the reference preview bundle so zero requests go to Google Fonts at runtime.
- **2026-11-13 (Phase 0)**: Kept the working brand name (`TFI & Pitch`) in English letters only under a single translation key (`brand.name`) and used Telugu in `brand.tagline` (`మన సినిమా, మన క్రికెట్, మన గ్యాంగ్`) per product rule 2.
- **2026-11-13 (Phase 0)**: Enforced Non-Negotiable Rule 1 (Telugu leads on every game card, title, and clue with English underneath, `line-height >= 1.5`, zero letter-spacing, never uppercased, and ~10% larger than English beside it) across all 10 games—including adding Telugu script titles for Cricket and Party games that had blank `te` strings in the raw HTML export.
- **2026-11-13 (Phase 0)**: Enforced Non-Negotiable Rule 4 & 7 on contrast and accessibility: used `--ink` (`#141313`) text on `--magenta` (`#EC1276`), `--yellow` (`#F6BE18`), `--green` (`#00C853`), and `--cyan` (`#00E5FF`) surfaces, reserving `--magenta` text exclusively for large bold/marker words on white or concrete backgrounds, and pairing every color indicator with text or an icon.
- **2026-11-13 (Phase 1)**: Built `/` (Landing) from the exported `TFI & Pitch Landing and App Preview – Landing page.html` and built `/play` (Play home) from the written layout spec, adding stub routes for `/play/[game]`, `/join`, `/me`, `/room/new`, `/about`, `/privacy`, `/terms`, and `/offline` so every navigation link works without 404s.
- **2026-11-13 (Step 0)**: English default, Telugu by switch — the app renders in English by default. Telugu script appears only when the user taps the "తె / EN" switch. This avoids surprising users who share devices, and keeps First Load JS smaller (Noto Sans Telugu not fetched until needed). Stored in cookie named `lang` ("en" or "te") for 1 year; server reads it on first paint so there is no flash. Decided by the product owner on 13 Nov 2026.
- **2026-11-13 (Phase 2)**: Head Set Go uses a plain React `useReducer` on the round screen (not XState) for the in-browser game loop, keeping the round page bundle small. The XState machine (`hsg-machine.ts`) lives in `@tfi/game-core` for use in future server-coordinated modes. Content pipeline (`pnpm content:build`) reads CSVs → validates with Zod → writes JSON to `packages/content/dist/` and copies to `apps/web/public/cards/` so the round page can `fetch()` them at runtime (also cacheable by the service worker).
- **2026-11-13 (Phase 3 - Step 0)**: Built Font Lab at `/dev/fonts` (noindex, unlinked) comparing Baseline vs 3 typography directions (Poster, Friendly party, Sharp) in both English and Telugu with sample conjuncts and words at 24/48/88px. Added CSS role variables (`--font-display`, `--font-accent`, `--font-body`, `--font-mono-role`, `--font-telugu-display`) in `:root` for one-line font swaps. Confirmed all candidate licenses (OFL 1.1 or Apache 2.0). Implemented Telugu mode fix: headings in Telugu mode use Noto Sans Telugu (weight 800) without uppercase, accent word uses bold Telugu in magenta on tilted white sticker, and tests enforce no system font fallbacks.
- **2026-11-13 (Phase 3)**: Unified Game Registry in `packages/game-core/registry.ts` as the single source of truth for all 10 games (metadata, category, mode, template, player limits, timer options, status). Generic turn-based Judge XState machine in `packages/game-core/judge-machine.ts` powers Transify, Emoji Cinema, Rapid Fire, and Cricket IQ, handling 2–8 player rotation, turn timer, scoring, and honest tie evaluation with 98.19% unit test line coverage.
- **2026-11-13 (Phase 3)**: Implemented 4 full games on the reusable Judge template (`/play/[game]`, `/round`, `/results`) with portrait view, answer strips, Web Audio beeps, haptics, Wake Lock, pause dialogs, and a 1080x1350 canvas share sticker with optional player name privacy. 180 total starter cards (30 cards across 6 decks) validated through the content pipeline with `verified: false`.
- **2026-11-13 (Phase 3b)**: Beta is movie-only; cricket and the rest return in the MVP (decided 13 Nov). Registry now has `release: "beta" | "mvp"`; Cricket IQ, Cricket Auction and Dream XI are `mvp` and hidden by default (code, decks and tests kept). `getVisibleGames(showMvp)` is the one place UI should ask; `SHOW_MVP_GAMES=true` will turn them on for development.
- **2026-11-13 (Phase 3b)**: Font direction A (Poster) chosen by the owner and applied. Only the Telugu font changes versus the old baseline: Anek Telugu (variable, weights 700 to 800, SIL Open Font License 1.1) replaces Noto Sans Telugu. Anton, Permanent Marker, Plus Jakarta Sans and Space Mono were already direction A and stay (all OFL 1.1 / Apache-style open licences, self-hosted in `public/fonts`, no runtime Google Fonts requests). Telugu font weight in Telugu mode: anek-telugu.woff2 139.7 KB + anek-telugu-latin.woff2 43.4 KB = 183 KB (budget 250 KB). It is requested only when Telugu text is on the page (unicode-range) and preloaded only for the lang=te cookie. Noto Sans Telugu is removed from production CSS; its files stay under `public/fonts` only so the dev-only `/dev/fonts` lab can still show the old baseline. Swapping fonts later is a change to the font variables plus the @font-face block.
- **2026-11-13 (Phase 3b Scope)**: Beta is movie-only; cricket and the rest return in the MVP (`release: "beta" | "mvp"`, toggled via `SHOW_MVP_GAMES=true`). Mode colors replace category colors: One phone = `#F6BE18` (yellow), Online = `#00E5FF` (cyan); green and magenta are reserved for Correct/Sold and Pass/Live.
- **2026-11-13 (Phase 3b Content & Games)**: Film (`films.csv`, 80 entries) and actor (`actors.csv`, 40 entries) master lists now power movie decks; `pnpm content:review` exports `review.csv` for human verification (`verified:false` by default). Rapid Fire rewritten to movie edition. Dumb Charades and Most Likely shipped with 3-step How-To-Play overlays, safe-area `100dvh` round screens, and 3 cycleable 1080x1350 Wall share templates.
- **2026-11-17 (Phase 4c Colors & Switch Subset)**: Restored all four palette accent colors with clear per-role jobs (`#F6BE18` primary action + one hero poster block, `#EC1276` Pass/Skip + Admit stub + <=10s warning with large bold white text `>=19px` for contrast, `#00C853` Correct + Ready offline ticks, `#00E5FF` online room codes + badges + Coming next strip). Built 2.0 KB `anek-telugu-switch.woff2` subset containing only `తె` so the language switch matches `EN` at weight 700 without loading full Telugu fonts in EN mode.
- **2026-11-17 (Phase 5 Online Rooms)**: Built PartyKit room foundation (`apps/realtime` with `main` + `registry` parties) and pure Zod/state engine in `@tfi/game-core`. Room codes use 4 unambiguous letters (`ABCDEFGHJKLMNPQRSTUVWXYZ`, no `I`/`O`), gated by `ENABLE_ROOMS` (default `false` in production, `true` in development). Implemented device-ID reconnect grace (5 min), host-away handover (60s -> longest-connected player), 6h idle expiry, 2 KB message cap, 20 msg/s general + 5 msg/s action rate limit, and short-term wrong-code rate limit (5 attempts / 30s per IP; stronger progressive backoff or CAPTCHA-free token buckets noted as a later hardening task in `OPEN_QUESTIONS.md`).
- **2026-11-17 (Phase 5 Name Filtering & Cost)**: Player names enforce length (1–16 chars), control-character stripping, whitespace collapse, and `"Guest Tiger"` defaults. A full Telugu + English profanity blocklist is deferred until native-speaker review (`OPEN_QUESTIONS.md`). Cloudflare / PartyKit free tier covers hobby traffic (up to 100k WebSocket requests/day / 3M Durable Object requests/month before paid Workers/PartyKit plan applies).
